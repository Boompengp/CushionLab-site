隐私政策

了解你的数据，存在哪里。

本政策说明 CushionLab App、公开支持网站和支持邮件中的信息处理方式。

更新及生效日期：2026-10-29

CushionLab App 无需注册账户，不把你的残局、笔记或练习进度上传到开发者服务器，也不包含广告或跨 App 跟踪。

设备上的数据

残局、笔记、学习进度、界面偏好与每日免费出杆计数保存在当前设备上。App 没有开发者运营的数据收集服务、第三方分析 SDK 或应用内云同步。设备备份是否包含这些本机数据，取决于你的 Apple 设置。

Pro 购买

Apple 处理 Pro 付款。App 使用 StoreKit 获取商品价格及验证购买、恢复、退款和撤销交易；验证后的交易凭据用于判断 Pro 权益。开发者不获得你的支付卡信息。Apple 对购买信息的处理适用 Apple 隐私政策。

管理和删除本机数据

可以在残局库编辑或删除单条保存记录。删除 App 会移除其本机数据；系统备份可能保留副本，具体以设备和备份设置为准。恢复 Pro 只恢复购买权益，不会恢复已删除的残局。已有设备备份的恢复由 Apple 提供，不必为了恢复购买而卸载 App。

本网站与外部链接

本网站由 GitHub Pages 托管，没有自行加入分析脚本、广告或追踪 Cookie。GitHub 会为安全目的记录和保存网站访问者的 IP 地址，无论访问者是否登录 GitHub。详情见 GitHub Pages 数据收集说明和 GitHub 隐私声明。

主动打开 Apple 条款、教学参考资料或其他外部网站时，适用相应服务提供方的隐私规则。邮件服务也与 App 分开运行。

主动联系支持

当你发送邮件至 justfret@163.com，我们会收到你提供的邮箱地址、邮件内容及附件，并将其用于处理你的问题或请求。请勿发送与问题无关的敏感信息。你也可以通过该邮箱咨询隐私问题或请求处理相关来信。

政策更新

如果后续功能改变数据处理方式，我们会更新本页面、生效日期、App 内隐私说明和适用的 App Store 隐私声明。
